# Website Deteksi Jari Berbasis AI

## Deskripsi Proyek

Proyek ini merupakan aplikasi web berbasis Artificial Intelligence (AI) yang dikembangkan untuk mendeteksi dan mengenali gestur jari menggunakan model machine learning dari Google Teachable Machine.

Website ini dibuat menggunakan HTML dan TensorFlow.js untuk mengintegrasikan model AI agar dapat digunakan melalui browser.

## Teknologi yang Digunakan

- **HTML** — membangun struktur halaman website.
- **JavaScript** — menjalankan fungsi dan proses deteksi.
- **TensorFlow.js** — menjalankan model machine learning di browser.
- **Google Teachable Machine** — melatih dan mengekspor model AI.

## Struktur Repository

```text
web_ai/
├── my_model/
│   ├── model.json
│   ├── metadata.json
│   └── bobot.bin
├── index.html
└── README.md
```

## Cara Menjalankan

1. Clone atau unduh repository ini.
2. Pastikan file model AI tersedia di dalam folder `my_model`.
3. Buka `index.html` melalui browser atau jalankan menggunakan server lokal.
4. Izinkan akses kamera jika diminta oleh website.
5. Arahkan jari ke kamera untuk mencoba proses deteksi.

## Tujuan Proyek

Proyek ini bertujuan menerapkan teknologi machine learning dalam aplikasi web sederhana serta mempelajari integrasi model AI ke dalam website.
